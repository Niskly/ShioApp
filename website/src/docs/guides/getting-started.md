# Getting started

Everything you need to start reading with Shio.

## Installation

### 1. Download Shio

Visit the [Download](/download/) page and tap the **Download Shio** button to get the latest APK.

### 2. Install the APK

1. Open the downloaded  file.
2. If Android asks, enable **Install unknown apps** for your browser or file manager.
3. Tap **Install** and wait for it to finish.

### 3. Open Shio

Launch Shio from your home screen or app drawer. You are ready to go.

## Reading manga and webtoons

1. Open the **Browse** tab.
2. Pick a source from the list.
3. Search or browse for a series.
4. Tap a series to open it, then tap a chapter to start reading.
5. Tap **Add to library** to save it for easy access later.

## Library

Your saved series live in the **Library** tab. From there you can:

- Track reading progress across all your series.
- Filter and sort by status, genre, or source.
- Start an update check to fetch the latest chapters.

## Backups

It is a good idea to back up your library regularly. See the [Backups guide](/docs/guides/backups) for instructions.
